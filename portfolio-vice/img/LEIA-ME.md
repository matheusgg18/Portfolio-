# 🖼️ Pasta de imagens

Coloque aqui os prints dos seus projetos e a sua foto. O site já aponta para estes nomes:

| Arquivo | Para quê | Situação |
| --- | --- | --- |
| `sistema-clinica.jpg` | Capa do Sistema de Clínica Médica | ✅ pronto |
| `sistema-clinica-1.jpg` a `-4.jpg` | Prévias: cadastro de paciente, cadastro de médico, listagem e detalhes | ✅ prontos |
| `portfolio-simples.jpg` | Capa do Portfólio Simples | ✅ pronto |
| `multilojas.jpg` | Capa do MultiLojas Marketplace | ⏳ falta o print |
| `atlas-da-pesquisa.jpg` | Capa do Atlas da Pesquisa | ⏳ falta o print |
| `researchhub.jpg` | Capa do ResearchHub | ⏳ falta o print |
| `clinica-stackblitz.jpg` | Capa da Clínica Médica (StackBlitz) | ⏳ falta o print |
| `prompt-fundamentos.jpg` | Capa de Engenharia de Prompt | ⏳ falta o print |
| `foto.jpg` | Sua foto (troque `photo` em `js/config.js`) | ⏳ opcional |
| `preview.png` | Imagem de compartilhamento do link e print para o README | ⏳ opcional |

Capas: proporção 4:3 (ideal 1200 × 900). Enquanto não houver imagem, o site mostra um cenário colorido.

## Como usar
1. Tire um print do projeto rodando (no Windows: **Win + Shift + S**).
2. Salve nesta pasta **com o nome da tabela** (ou use outro nome e ajuste `cover` em `js/config.js`).
3. Atualize o site (Ctrl + F5).

## Dicas
- Prefira `.jpg` ou `.webp` e mantenha cada arquivo abaixo de ~300 KB para o site carregar rápido.
- Imagens extras de um projeto (`previews`, até 4) podem ter qualquer nome. As prévias aparecem inteiras, sem corte.
- No GitHub, maiúsculas e minúsculas importam: `Foto.jpg` e `foto.jpg` são arquivos diferentes.
